## BandwagonHost Benchmark 数据：各机房实测结果

这部分是大多数对比文章缺少的内容。以下数据来自 2025 年多位用户使用 bench.sh 和 yabs.sh 脚本的实测，不是官方宣传数字。

### DC9（USCA\_9）——洛杉矶，已升级 AMD + NVMe

DC9 是目前搬瓦工常规套餐中硬件最新的一个美国机房。

根据 Bandwagonhost 中文网 2025 年实测数据：

- **CPU**：AMD EPYC-Genoa，6 核 @ 约 2445 MHz
- **Geekbench 6 单核**：约 1466 分
- **Geekbench 6 多核**：约 6455 分
- **NVMe 磁盘读写**：平均接近 1 GB/s
- **三网延迟**：均在 200ms 以内，实际平均约 150ms（电信/联通/移动）
- **丢包率**：三网基本 0 丢包
- **回程线路**：电信和联通接入 CN2 GIA，移动接入 CMIN2

一句话总结：DC9 的 AMD EPYC 和 NVMe 组合在这个价位算是满分硬件，线路同样是顶配。

### DC6（USCA\_6）——洛杉矶，Intel Xeon + 旋转盘（暂未升级）

DC6 是搬瓦工的旗舰 CN2 GIA-E 机房，但硬件比 DC9 老一代。根据 2025 年 bench.sh 实测：

- **CPU**：Intel Xeon（SierraForest），6 核 @ 约 2600 MHz
- **内存**：7.8 GB
- **平均 I/O 速度**：约 565.7 MB/s（明显低于 DC9 的 NVMe）
- **Geekbench 6 单核**：约 412 分（低于 DC9 较多）
- **本地网络吞吐**：上传 7778 Mbps / 下载 7394 Mbps
- **到东京下载速度**：约 5675 Mbps
- **CN2 GIA 三网延迟**：平均约 158.6ms，丢包接近 0

DC6 的网络能力非常强，但 CPU 跑分明显落后于 DC9，适合更看重线路稳定、对 CPU 运算需求不高的用户。

### 加拿大温哥华（CABC\_6）——AMD + NVMe，2025 年升级

温哥华机房在 2025 年完成了硬件升级，表现接近 DC9。根据实测：

- **CPU**：AMD EPYC，6 核高主频
- **磁盘 I/O**：平均 1228.8 MB/s（fio 混合读写远超普通 SSD）
- **三网 CN2 GIA 回程**：电信、联通、移动全覆盖
- **延迟**：从国内测试延迟中规中矩，略高于洛杉矶

适合有加拿大或北美西部方向访问需求，或想要高性能磁盘的用户。

### 香港（HKHK\_8）——延迟最低，价格也最高

香港机房是搬瓦工最贵的选项，Equinix HK2 机房，物理距离最近。

- **理论延迟**：部分城市单程延迟可做到个位数毫秒
- **线路**：CN2 GIA（电信）+ 直连（联通/移动）
- **月费**：起步 $89.99/月

适合实时性要求极高的场景：金融交易、低延迟游戏、视频会议。

## FAQ：搬瓦工常见问题

**Q：BandwagonHost benchmark 跑分怎么样？和 Vultr、DigitalOcean 比谁更好？**

A：在 CPU 原始跑分上，搬瓦工 DC9 的 AMD EPYC 单核约 1466 分，竞争力较强。根据 DEV Community 2026 年的独立测试，从中国访问时 Vultr Tokyo 和 Linode Tokyo 的延迟和吞吐量数据略好于搬瓦工 CN2 GIA（洛杉矶），但搬瓦工在跨境路由稳定性和晚高峰零丢包方面表现更可预期。两者各有侧重，不是简单的谁比谁更好。

**Q：CN2 GIA 和普通线路的区别是什么，真的有必要吗？**

A：CN2 GIA（中国电信全球互联网接入）是中国电信最贵的一类 IP 线路，专属带宽，不与普通互联网流量混用。根据搬瓦工官网说明，普通国际线路在晚高峰丢包率可达 30% 以上，CN2 GIA 则保持极低丢包。如果你的业务需要从中国访问，或者你人在中国需要稳定外网连接，CN2 GIA 的差别很明显。如果你只是跑个不需要连国内的海外服务，普通 GT 线路也够用。

**Q：搬瓦工是自管 VPS，适合新手吗？**

A：需要基本的 Linux 命令行能力。搬瓦工不提供 cPanel，不帮你装 WordPress，支持工单响应但不是即时聊天。如果你能在 SSH 里执行几条安装命令、会用 apt 或 yum，完全可以用。如果你完全没有 Linux 经验，建议先学 2-3 周基础再入手。
